# 文字雷達（PaddleOCR 後端版）

此工具使用本機 FastAPI 與 PaddleOCR 辨識圖片中的繁體中文、英文與數字，並在瀏覽器中標記符合搜尋文字的位置。

## 啟動

在 Windows 雙擊 `啟動.bat`。首次啟動會建立 `.venv`、安裝 Python 套件，並在第一次辨識時下載 PaddleOCR 模型到本機快取。完成後開啟 `http://127.0.0.1:8123`。

不要直接用 `file://` 開啟 `index.html`，必須透過本機伺服器使用。

## 隱私

圖片只會傳給同一台電腦上的 `127.0.0.1` 後端；沒有串接雲端 OCR API。首次安裝套件與下載模型時才需要網路。
